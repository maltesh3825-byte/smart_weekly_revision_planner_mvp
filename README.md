**Smart Weekly Revision Planner for Class 8 Students**

Project: full-stack MVP (React frontend + Flask backend) using Google Gemini (optional) for AI generation.

Project structure

frontend/
 ├── src/
 │    ├── components/
 │    ├── pages/
 │    ├── App.js
 │    ├── App.css

backend/
 ├── app.py
 ├── requirements.txt
 └── .env.example

Setup — Backend

1. Create a Python virtualenv and install requirements:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r backend/requirements.txt
```

2. Create a `.env` file from `.env.example` and set `GEMINI_API_KEY` (optional):

```
GEMINI_API_KEY=your_gemini_api_key_here
```

3. Run the backend:

```powershell
python backend/app.py
```

Notes on Gemini integration
- The Flask app reads `GEMINI_API_KEY` from environment.
- Example Gemini prompt is included inside `backend/app.py` in `build_gemini_prompt()`.
- The code uses a sample REST call to the Generative Models endpoint. Adjust endpoint and client per Google's official SDK in production.
- If `GEMINI_API_KEY` is missing or the API call fails, the backend returns a friendly dummy response so the frontend still works.

Setup — Frontend

This repo contains a minimal React scaffold inside `frontend/src` for demo purposes.
You can use any React toolchain (create-react-app, Vite) and copy the `src` folder.

Quick start with a simple static server (recommended for hackathon demo):

1. Use `create-react-app` or Vite and replace `src` with the provided `frontend/src`.
2. Run the dev server and open `http://localhost:3000` (or your toolchain's URL).

How it works
- Home: start the flow.
- Revision Input: choose subject, chapter, pages, exam type and submit.
- Backend `/generate-revision` builds a prompt, calls Gemini (if key present) and returns JSON: `{ summary, mcqs, short_questions, long_questions }`.
- Revision Plan: shows weekly schedule and the 30-minute summary.
- Questions: shows 6 MCQs, 2 short and 2 long questions generated by the AI (or dummy data).

Important
- No Firebase, no DB, no authentication.
- Beginner-friendly code with comments.
